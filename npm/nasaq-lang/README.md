# @nasaq/lang

Official npm wrapper for the **Nasaq** (نَسَق) compiler.

```bash
npm install -g @nasaq/lang
nasaq new myapp --template web
nasaq dev .
```

Requires the `nasaq` binary (`cargo install --path crates/nasaq_cli`) or `NASAQ_BIN` pointing to it.

See [github.com/nasaq-lang/nasaq](https://github.com/nasaq-lang/nasaq).
